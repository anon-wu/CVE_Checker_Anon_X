🚀

Zero-Dependency 단일 실행 파일

Python, .NET 런타임 설치, 별도 데이터베이스 없이 Windows 내장 .NET Framework 4.8에서 즉시 실행됩니다. 폐쇄망 USB에서도 바로 동작합니다.

🛡️

글로벌 21종+ 백신 무간섭 공존

커널 드라이버(.sys) 설치, 메모리 인젝션, 백신 설정 강제 수정을 절대 사용하지 않습니다. V3, 알약, Defender, CrowdStrike와 100% 공존합니다.

🔄

원클릭 스냅샷 원상 복구

무통보 변경은 0건입니다. 사용자가 [허용(Allow)]을 승인한 항목만 이전 상태를 스냅샷 백업한 뒤 적용하며, 언제든 1초 만에 롤백할 수 있습니다.

🌐

한·영·일 3개 국어 네이티브 UI

창 재생성 없이 < 30ms 이내에 한국어, 영어, 일본어(Noto Sans JP)로 즉시 전환되어 글로벌 다국적 기업 보안 관제에 최적화되었습니다.

💻

CLI & 무인 CI/CD 파이프라인

--cli 및 --batch 옵션을 통해 관리자 자동화 스크립트, 감사 증적 자동 수집, 보안 파이프라인에 완전하게 통합됩니다.

🔐

RSA-2048 전자서명 무결성

Microsoft 공식 Strong-Name 서명 및 [SuppressIldasm], Roslyn 심볼 난독화가 결합되어 악의적인 코드 변조 및 역공학을 원천 차단합니다.
