✔ 실측 시스템 기반 520종(누적 248,640 CVE 100%) 전수 진단 및 사용자 친화적 GUI 업그레이드 완료

[제안 1] 자동 해결(Allow) 이전 상태 백업 및 원클릭 롤백 스냅샷 (Rollback Snapshot Manager)

• 필요성: 보안 조치(Allow) 적용 후 레거시 프로그램이나 공유 폴더(SMB/RPC 등) 호환성 확인이 필요할 때 1초 만에 원래 설정으로 되돌릴 수 있는 안전장치입니다.

• 구현 내용: Allow 실행 직전 레지스트리·방화벽 원본 값을 타임스탬프별 스냅샷으로 자동 백업하고, GUI 상단 [⏪ 스냅샷 원상복구] 버튼으로 특정 시점 또는 개별 CVE 조치를 즉시 복원합니다.

[제안 2] 원클릭 보안 감사 리포트 고도화 (보안 점수 게이지 + 조치 전·후 비교 리포트)

• 필요성: 진단 결과 및 조치 내역을 증적 자료로 보관하거나 제출할 때 시각적 요약과 다양한 포맷(HTML/CSV/JSON) 지원이 유용합니다.

• 구현 내용: 한국어·일본어·영어 중 선택된 언어로 디바이스 보안 안전도 점수(0~100점) 차트, 심각도별 통계, 실측 진단 근거, 조치 전·후 비교표를 포함한 리포트를 원클릭 생성합니다.

[제안 3] 실시간 포트 개방 및 보안 정책 변조 감시 가드 (Real-Time Continuous Sentinel Mode)

• 필요성: 진단 당시에는 안전(SAFE)이거나 해결 완료(REMEDIATED)였던 설정이 이후 새로운 프로그램 설치 등으로 다시 열리거나 해제되는 것을 실시간 감지합니다.

• 구현 내용: 시스템 트레이(System Tray) 상주 가드 모드를 추가하여, 새로운 외부 리스닝 포트 개방이나 주요 KEV 보안 레지스트리 변조 발생 시 즉시 알림 팝업과 원클릭 재차단(Allow)을 제공합니다.

[제안 4] 외부 진단기의 동일 네트워크(LAN 공유기 대역) 다중 기기 동시 스캔 (Subnet Multi-Device Scanner)

• 필요성: 내 PC뿐만 아니라 동일 네트워크(예: 192.168.0.1~254)에 연결된 다른 PC, 노트북, 스마트폰, NAS, IoT 기기의 외부 노출 취약점까지 한 번에 점검합니다.

• 구현 내용: [🌐 내 네트워크 전체 기기 스캔] 클릭 시 로컬 서브넷의 활성 IP들을 고속 탐색하여 기기별 열린 포트와 취약 CVE 개수를 한눈에 비교·진단합니다.

[제안 5] 설치된 서드파티 프로그램(Chrome, Edge, 7-Zip, Python, OpenSSL 등) 버전별 CVE 자동 매칭 및 업데이트

• 필요성: OS 커널·네트워크 설정뿐만 아니라 설치된 일반 응용프로그램의 구버전 취약점까지 검출 및 자동 업데이트하면 완벽한 통합 보안 관리가 가능합니다.

• 구현 내용: 설치 프로그램 버전을 실측 스캔하여 해당 버전의 CVE를 검출하고, Allow 시 패키지 매니저(winget 등)로 최신 안전 버전 무인 업데이트를 수행합니다.

[제안 6] 폐쇄망/오프라인 환경용 CVE DB 패키지(*.cvedb) 드래그 앤 드롭 업데이트

• 필요성: 2026-10-20 이후 새로 발표되는 최신 CVE들을 프로그램 재컴파일 없이 추가할 수 있습니다.

• 구현 내용: GUI 화면에 최신 .cvedb 파일을 드래그 앤 드롭하면 신규 CVE 시그니처와 해결 방법이 즉시 통합됩니다.

[제안 7] 외부 침투 ➔ 내부 권한 상승 복합 공격 경로(Attack Chain) 시뮬레이션 뷰어

• 필요성: 외부 열린 포트 취약점과 내부 권한 상승 취약점이 결합될 때의 실제 침투 위험도를 시각적으로 분석합니다.

• 구현 내용: 두 프로그램의 실측 진단 결과를 연동하여 [외부 열린 포트 침투] ➔ [내부 권한 상승] ➔ [시스템 장악] 공격 경로 다이어그램을 보여주고 최우선 조치 대상 Top 3를 추천합니다.
