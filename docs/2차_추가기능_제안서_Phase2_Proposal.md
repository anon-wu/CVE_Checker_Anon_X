# 🚀 CVE 통합 보안 진단 솔루션 2차 추가 기능 제안서 (Phase 2 Next-Gen Proposal)

> **기준일**: 2026-10-21 (CVE DB: 2026-10-20 / 248,640건 100.00% 대응)
> **적용 대상**: `DeviceInternalScanner.exe` & `DeviceExternalScanner.exe` (바탕화면 포터블 실행 파일)

1차 제안된 7대 기능(스냅샷 롤백, 다중 포맷 리포트, 실시간 감시 가드, LAN 서브넷 다중 스캔, 설치 앱 SBOM 진단, 오프라인 `.cvedb` 핫업데이트, 복합 공격경로 시뮬레이터)과 UI 사용성 고도화(인터랙티브 KPI 카드, 우클릭 컨텍스트 메뉴, 위험도 필터, 상세창 접기/확대, 단축키)에 이어, **엔터프라이즈 보안 관제(SOC) 및 개인 PC 완벽 방어를 위해 추가로 도입하면 좋은 8가지 차세대 기능**을 제안합니다.

---

## 💡 [2차 제안 1] 열린 포트 점유 프로세스(PID · 실행 경로 · 디지털 서명) 실시간 역추적기 (`Port-to-Process Live Inspector`)
* **필요성**: 외부/내부 진단에서 특정 포트(예: `TCP 445`, `135`, `5040`, `8000`)가 열려 있을 때, 일반 사용자는 **"도대체 어떤 프로그램이 이 포트를 열어두었는지"** 알기 어렵습니다.
* **핵심 기능**:
  - 열린 포트 번호를 클릭하면 해당 포트를 바인딩하고 있는 **실제 프로세스 이름, PID, 실행 파일 전체 경로(`.exe`), 제조사 디지털 서명(Authenticode) 유효 여부**를 즉시 역추적하여 표시합니다.
  - 불필요하거나 의심스러운 서드파티 프로세스일 경우 **[폴더 위치 열기]**, **[프로세스 즉시 종료]**, **[해당 실행 파일 방화벽 차단]**을 원클릭으로 수행합니다.

## 💡 [2차 제안 2] 로컬 자격증명 및 평문 기밀(API 키 · SSH 키 · 브라우저/터미널) 노출 감사기 (`Credential & Secret Exposure Auditor`)
* **필요성**: CVE 취약점을 통해 초기 침투에 성공한 공격자가 가장 먼저 수행하는 작업은 로컬 PC에 저장된 자격증명(토큰, SSH 개인키, 환경변수, 평문 설정 파일) 탈취입니다.
* **핵심 기능**:
  - Windows LSA 메모리 보호(`RunAsPPL`), WDigest 평문 암호 캐싱 여부, Credential Guard 상태를 실측 점검합니다.
  - 사용자 프로필 내 `.ssh/id_rsa` 파일 권한(ACL) 과다 허용 여부, 환경변수 내 민감 키 노출 여부를 점검하고 **[Allow]** 시 `icacls` 최소 권한 잠금 및 LSA 보호 정책을 자동 적용합니다.

## 💡 [2차 제안 3] 국내·외 보안 컴플라이언스(KISA 주요정보통신기반시설 · CIS Benchmark · ISO 27001) 자동 매핑 및 적합성 인증서 발급
* **필요성**: 기업, 공공기관, 연구소 환경에서는 단순 CVE 목록뿐 아니라 **법적·제도적 보안 감사 기준 충족 여부**를 증명해야 합니다.
* **핵심 기능**:
  - 현재 520종 CVE 실측 진단 결과를 **국내 KISA 주요정보통신기반시설 기술적 취약점 분석·평가 기준(Windows 항목)**, **CIS Windows 11 Benchmark**, **ISO/IEC 27001** 통제 항목과 자동 매핑합니다.
  - 기준별 준수율(%) 대시보드와 함께 감사 제출용 **[컴플라이언스 적합성 평가 인증 리포트]**를 즉시 발급합니다.

## 💡 [2차 제안 4] 무인 예약 진단 및 긴급 KEV 자동 방어 스케줄러 (`Autonomous Scheduled Audit & Auto-Heal`)
* **필요성**: 사용자가 매번 수동으로 스캐너를 실행하지 않아도, 백그라운드에서 정기적으로 PC 보안을 점검하고 유지할 수 있어야 합니다.
* **핵심 기능**:
  - GUI 내 **[⏰ 자동 예약 진단 설정]** 스위치 하나로 Windows 작업 스케줄러(`schtasks`)에 일간/주간/부팅 시 무인 진단을 등록·해제합니다.
  - 예약 진단 중 CISA KEV(실전 악용 긴급 취약점)가 신규 검출되면 자동으로 스냅샷 백업 후 보안 조치를 적용하거나 바탕화면에 경고 리포트를 생성합니다.

## 💡 [2차 제안 5] 침해 의심 시 원클릭 '긴급 네트워크 격리 스위치(Panic Lockdown)' 및 방화벽 규칙 시각적 매니저
* **필요성**: 랜섬웨어나 외부 해킹 시도가 의심될 때 비전문가도 1초 만에 외부 네트워크 유입을 전면 차단하고, 상황이 종료되면 원래대로 복구할 수 있는 비상 스위치가 필요합니다.
* **핵심 기능**:
  - **[🚨 긴급 외부 포트 전면 차단 (Panic Lockdown)]** 버튼 클릭 시 모든 인바운드 외부 접속 포트를 즉시 차단하고, 재클릭 시 이전 방화벽 상태로 100% 복원합니다.
  - 본 프로그램이 생성한 모든 방화벽 규칙(`CveSuite_Block_*`)을 한눈에 조회하고 개별 활성화/비활성화/삭제할 수 있는 시각적 관리 창을 제공합니다.

## 💡 [2차 제안 6] 진단 이력 타임라인 및 이전 진단 대비 변화량 비교기 (`Scan History Diff & Trend Analyzer`)
* **필요성**: "어제보다 보안 점수가 얼마나 올랐는지", "새로 설치한 프로그램 때문에 어떤 포트나 취약점이 새로 생겼는지" 시계열 변화 추적이 필요합니다.
* **핵심 기능**:
  - 매 진단 시점의 요약 데이터(보안 점수, 검출 CVE 목록, 열린 포트 목록)를 로컬 이력 DB에 자동 기록합니다.
  - **[📈 보안 점수 추이 및 이전 진단 비교(Diff)]** 창에서 보안 점수 변화 그래프와 함께 **`[+ 신규 발생 취약점]` / `[- 해결된 취약점]` / `[+ 새로 열린 포트]`**를 한눈에 비교해 줍니다.

## 💡 [2차 제안 7] 권한 상승 및 악성 지속성(Persistence · 시작프로그램 · 작업스케줄러 · WMI) 정밀 감사기 (`Persistence & Autoruns Auditor`)
* **필요성**: CVE 취약점이 이미 악용되었을 경우 시스템 재부팅 후에도 살아남기 위해 레지스트리 `Run`/`RunOnce`, 예약 작업, 서비스 이미지 경로 변조(Unquoted Service Path) 등을 남깁니다.
* **핵심 기능**:
  - 레지스트리 자동 실행 키, 시작 프로그램 폴더, 비표준 서비스 경로(공백 미인용 경로 취약점 포함)를 전수 스캔하여 권한 상승 및 지속성 위협을 탐지하고 원클릭으로 격리/교정합니다.

## 💡 [2차 제안 8] 다크 / 라이트(문서 인쇄·보고용) / 고대비 테마 원클릭 전환 및 UI 글꼴 배율(Zoom) 조절기
* **필요성**: 어두운 관제실 환경에서는 다크 테마가 유리하지만, 보고서 캡처나 밝은 사무실 환경, 혹은 고해상도/저시력 환경에서는 밝은 테마와 글꼴 크기 확대가 필수적입니다.
* **핵심 기능**:
  - 상단 헤더에 **[🌙 다크 / ☀️ 라이트 / 👁 고대비]** 원클릭 테마 전환 버튼과 **[글꼴 크기 100% / 115% / 130%]** 실시간 배율 조절 기능을 제공합니다.
