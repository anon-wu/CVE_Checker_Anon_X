PHASE 2 NEXT-GEN SECURITY PROPOSAL (2026-10-21)

🚀 CVE 통합 보안 진단 프로그램 — 2차 추가 기능 제안서 (8대 신규 기능)

1차 7대 기능 및 UI 사용성 대폭 강화(인터랙티브 KPI 카드, 우클릭 메뉴, 위험도 필터, 상세창 접기/확대, 단축키) 적용 완료 후, 추가로 도입 가능한 차세대 보안 기능 제안입니다.

2차 제안 1 · 네트워크/프로세스 역추적

🔍 열린 포트 점유 프로세스(PID · 경로 · 서명) 실시간 역추적기

  • 열린 포트(예: 445, 135, 5040, 8000)를 실제로 점유 중인 프로세스 이름, PID, 실행 파일 전체 경로, 디지털 서명 유효성을 즉시 역추적합니다.
  • 원클릭으로 [파일 위치 열기], [의심 프로세스 종료], [방화벽 차단]을 지원합니다.
2차 제안 2 · 기밀 유출 방어

🔐 로컬 자격증명 및 평문 기밀(LSA · SSH 키 · 환경변수) 노출 감사기

  • 공격자가 침투 후 노리는 WDigest 평문 암호 캐싱, LSA 보호(RunAsPPL) 미설정, .ssh 개인키 과다 권한 허용을 실측 진단합니다.
  • [Allow] 시 최소 권한(icacls) 잠금 및 LSA 메모리 보호 정책을 즉시 적용합니다.
2차 제안 3 · 규정 준수 및 감사

📜 KISA 주요정보통신기반시설 · CIS Benchmark · ISO 27001 컴플라이언스 매핑

  • 520종 CVE 실측 진단 결과를 국내 KISA 기술적 취약점 분석·평가 기준 및 CIS Windows 11 Benchmark 항목과 자동 매핑합니다.
  • 규정 준수율(%) 산출 및 감사 제출용 적합성 인증 리포트를 발급합니다.
2차 제안 4 · 무인 자동화

⏰ 무인 예약 진단 및 긴급 KEV 자동 방어 스케줄러

  • 사용자가 수동 실행하지 않아도 매일/매주 지정된 시각에 백그라운드 진단을 수행하도록 Windows 작업 스케줄러를 원클릭 등록/해제합니다.
  • 신규 CISA KEV 취약점 감지 시 스냅샷 백업 후 자동 방어 조치를 수행합니다.
2차 제안 5 · 비상 대응

🚨 원클릭 '긴급 네트워크 격리 스위치(Panic Lockdown)' 및 방화벽 매니저

  • 침해 의심 시 클릭 한 번으로 외부 인바운드 포트를 즉시 전면 차단하고, 재클릭 시 원상복구하는 비상 격리 스위치를 제공합니다.
  • 적용된 모든 방화벽 규칙을 시각적으로 조회·개별 해제할 수 있습니다.
2차 제안 6 · 시계열 변화 분석

📈 진단 이력 타임라인 및 이전 진단 대비 변화량(Diff) 비교기

  • 매 진단 결과를 타임라인에 기록하여 "이전 진단 대비 새로 발생한 취약점 / 해결된 취약점 / 새로 열린 포트"를 비교(Diff)합니다.
  • 디바이스 보안 점수 추이 그래프를 시각화합니다.
2차 제안 7 · 지속성 위협 탐지

🛡 권한 상승 및 지속성(시작프로그램 · 서비스 경로 · 작업스케줄러) 감사기

  • 공격자가 남기는 레지스트리 Run/RunOnce, WMI 구독, 공백 미인용 서비스 경로(Unquoted Service Path) 취약점을 실측 스캔합니다.
  • 위험 자동 실행 항목을 원클릭으로 격리 및 교정합니다.
2차 제안 8 · 시각 접근성 향상

🎨 다크 / 라이트(인쇄·보고서용) / 고대비 테마 및 UI 글꼴 배율(Zoom) 제어

  • 관제용 다크 테마, 보고서 캡처용 라이트 테마, 시인성 극대화용 고대비 테마를 원클릭 전환합니다.
  • UI 전체 글꼴 배율(100% / 115% / 130%)을 실시간 확대·축소합니다.
