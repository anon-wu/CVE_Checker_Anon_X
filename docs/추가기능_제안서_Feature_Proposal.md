## 💡 승인 시 즉시 추가 제작 가능한 7대 차세대 기능 제안

### [제안 1] 자동 해결(`Allow`) 이전 상태 백업 및 원클릭 롤백 스냅샷 (Rollback Snapshot Manager)
- **필요성**: 보안 조치(`Allow`)로 인해 특정 레거시 프로그램이나 사내 네트워크 공유(예: SMB, RPC, 구형 TLS)가 차단되었을 때, 언제든 이전 상태로 되돌릴 수 있는 안전장치가 있으면 훨씬 안심하고 사용할 수 있습니다.
- **구현 내용**:
  - `Allow` 실행 직전 변경 대상 레지스트리 값 및 방화벽 규칙의 **원본 상태를 타임스탬프별 스냅샷으로 자동 백업**합니다.
  - GUI 상단 `[⏪ 스냅샷 복구(Rollback)]` 버튼 및 CLI `--rollback` 옵션을 통해 원하는 시점이나 특정 CVE 조치만 **1초 만에 원상 복구**합니다.

### [제안 2] 원클릭 보안 감사 리포트 고도화 (보안 점수 차트 + 조치 전·후 비교 PDF/HTML/CSV/JSON)
- **필요성**: 진단 결과 및 조치 내역을 문서로 보관하거나 보고서로 활용할 때 시각적 요약과 데이터 내보내기가 필요합니다.
- **구현 내용**:
  - 한국어·일본어·영어 중 현재 선택된 언어로 **디바이스 보안 안전도 점수(0~100점) 게이지, 심각도별 통계 차트, 실측 진단 근거, 조치 전·후 비교표**가 포함된 대화형 리포트(`.html`, `.csv`, `.json`) 및 인쇄용 레이아웃을 생성합니다.

### [제안 3] 실시간 포트 개방 및 보안 정책 변조 감시 가드 (Real-Time Continuous Sentinel Mode)
- **필요성**: 진단 당시에는 닫혀 있던 포트(`SAFE`)나 해결 완료(`REMEDIATED`)된 설정이 새로운 프로그램 설치 등으로 인해 다시 열리는 것을 실시간으로 막아줍니다.
- **구현 내용**:
  - Windows 시스템 트레이(System Tray) 아이콘 또는 백그라운드 가드 모드로 동작하며, **새로운 외부 리스닝 포트 개방이나 주요 KEV 보안 레지스트리 변조 발생 시 즉시 알림 팝업**을 띄우고 원클릭 재차단(`Allow`)을 지원합니다.

### [제안 4] 외부 진단기의 동일 네트워크(LAN 공유기 대역) 다중 기기 동시 스캔 (Subnet Multi-Device Scanner)
- **필요성**: 현재 사용 중인 PC뿐만 아니라 같은 공유기/네트워크(`예: 192.168.0.1 ~ 192.168.0.254`)에 연결된 다른 PC, 노트북, 스마트폰, NAS, IoT 기기의 외부 노출 취약점까지 한 번에 점검할 수 있습니다.
- **구현 내용**:
  - `[🌐 내 네트워크 전체 기기 스캔]` 버튼 클릭 시 로컬 서브넷의 활성 IP들을 고속 탐색하여, 기기별 열린 포트와 취약 CVE 개수를 대시보드 형태로 한눈에 보여줍니다.

### [제안 5] 설치된 서드파티 프로그램(Chrome, Edge, 7-Zip, Python, OpenSSL 등) 버전별 CVE 자동 매칭 및 업데이트
- **필요성**: OS 자체 취약점뿐만 아니라 사용자가 설치한 일반 응용프로그램의 구버전 취약점까지 잡아내면 완벽한 통합 보안 솔루션이 됩니다.
- **구현 내용**:
  - PC에 설치된 모든 프로그램의 실제 버전을 스캔하여 해당 버전의 CVE를 검출하고, `Allow` 클릭 시 `winget` 등을 통해 **최신 안전 버전으로 무인 자동 업데이트**를 수행합니다.

### [제안 6] 폐쇄망/오프라인 환경용 CVE DB 파일(`*.cvedb`) 드래그 앤 드롭 업데이트
- **필요성**: `2026-10-20` 이후 새롭게 발표되는 최신 CVE들을 프로그램 재설치 없이 추가할 수 있습니다.
- **구현 내용**:
  - GUI 창에 최신 `.cvedb` (또는 `.json`) 파일을 마우스로 끌어다 놓기(Drag & Drop)만 하면, 신규 CVE 시그니처와 해결 방법이 즉시 DB에 병합됩니다.

### [제안 7] 외부 침투 ➔ 내부 권한 상승 복합 공격 경로(Attack Chain) 시뮬레이션 뷰어
- **필요성**: 외부 진단기에서 발견된 열린 포트 취약점과 내부 진단기에서 발견된 권한 상승 취약점이 결합될 때 얼마나 위험한지 직관적으로 보여줍니다.
- **구현 내용**:
  - 두 프로그램의 실측 진단 결과를 연동하여 **`[외부 열린 포트 침투] ➔ [내부 서비스 권한 상승] ➔ [시스템 관리자 탈취]`** 공격 경로 다이어그램을 시각화하고, 가장 먼저 막아야 할 핵심 취약점 Top 3를 추천해 줍니다.
